# Pilates Flow Builder PWA

Aplicación Web Progresiva (PWA) de planificación de clases de Pilates y modo de enseñanza en sala para profesoras e instructoras.

## Características
- **PWA 100% Offline**: Funciona en iPad/Android sin conexión a internet.
- **Traductor de Resortes Multi-marca**: Balanced Body, Peak Pilates, Gratz, Merrithew, Elina.
- **Planificador Visual**: Diseñador de clases en 3 columnas con barra de tiempo inteligente.
- **Modo en Sala**: Pantalla gigante de lectura rápida a 1 metro de distancia durante la enseñanza.

## Instrucciones de Instalación
1. Descarga y descomprime `pilates-flow-pwa.zip`.
2. Sube el contenido a tu repositorio de GitHub.
3. Conecta el repositorio con Netlify para desplegarla en 30 segundos.
